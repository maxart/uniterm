The harness enforces these controls:

- Equivalent workloads use isolated HOME/XDG trees and real PTYs; product commands only set up, probe, and stop sessions.
- Startup order reverses; suite order rotates by seed. Latency/output screen checks gate validity. Root and cohort metrics are separate.
- Herdr background checks are disabled and its headless geometry is pinned. tmux uses a private socket/config, a non-login shell and tiled prefix-key splits.
- Output privacy: host identities, paths, wall-clock timestamps, custom text, raw diagnostics and terminal contents are omitted. Counts, measurements and revision/artifact hashes are retained.
- Geometry is 160x50; the live workload uses 16 panes and 50000 deterministic output lines.

## Claim guidance and limitations

Safe marketing use requires all of the following:

- Publish the raw JSON, tool revision, app revisions, profile, host details, and exact binaries or hashes.
- Say "in our measured workload" and name the OS/hardware. Do not generalize one machine to every installation.
- Use the `marketing` profile for public CPU claims; smoke results validate the harness but are too short for stable idle-CPU claims.
- Repeat on native Linux, WSL2, Intel/Apple Silicon macOS as relevant, with at least three runs per host and alternating product order.
- Do not describe the assurance checklist as an audit, certification, exploit test, or guarantee.
- Re-run after either binary, configuration, dependency lockfile, or benchmark tool changes.

Known limitations:

- PTY latency intentionally includes the same `/bin/sh` scheduling and rendering path for both products; it is end-to-end, not an internal parser microbenchmark.
- RSS is sampled from `ps`; allocator-resident versus reclaimable memory is not separated.
- CPU resolution and background system noise limit very short runs.
- Feature breadth is not folded into the performance score. A faster result does not imply feature parity.
- Manual assurance findings are point-in-time source review and must be revisited when implementations change.
